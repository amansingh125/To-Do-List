# Todo List App

## 📌 Overview

Todo List App is a task management application designed to help users organize daily activities efficiently. The application provides a simple and intuitive interface for creating, updating, tracking, and removing tasks. It focuses on improving productivity by allowing users to manage their work in a structured way.

## ✨ Features

* Add new tasks instantly
* Edit existing tasks
* Delete unwanted tasks
* Mark tasks as completed
* Filter completed and pending tasks
* Persistent storage using Local Storage
* Clean and responsive user interface
* Real-time task updates

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6+)
* HTML5
* CSS3
* Local Storage API

1. Clone the repository.
2. Install project dependencies.
3. Start the development server.
4. Open the application in your browser.

## 🎯 Key Functionalities

### Task Creation

Users can create tasks by entering a description and saving it to the list.

### Task Management

Tasks can be edited whenever changes are required and removed when they are no longer needed.

### Completion Tracking

Completed tasks can be marked using a checkbox, making it easy to distinguish finished work from pending tasks.

### Data Persistence

Tasks are automatically saved in the browser's Local Storage, ensuring data remains available after page refreshes or browser restarts.
